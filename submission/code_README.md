# CS781 capstone code: Aryan Kumar (261110012)

Indian legal NLP in seven phases, every model trained from our own Phase 1 pretraining (no outside pretrained weights).
All training ran on Google Colab. Model weights, checkpoints, datasets and submission files are not included, as the assignment requires.
The data comes from the gated Hugging Face dataset `Exploration-Lab/CS-781-Capstone`; `phase1/common/download_data.py` fetches a phase's files with an `HF_TOKEN` taken from the environment.

Colab notebooks expect the course Drive folder `MyDrive/legal-llm-course/` to hold the phase library (`*_lib.py`), `phase2_lner_multimethod_bundle.zip`
(the contents of `phase1/common/` plus `phase2/legal_ner.py`) and the Phase 1 checkpoints. Most notebooks are generated by a `make_notebooks.py` in the same folder, so defaults are edited there.

## Folder map

```
phase1/common/            course scaffold (legal_scaffold), training_methods.py (full, LoRA, LoRMA, IA3, distillation), frozen BPE tokenizer, data download
phase1/original_models/   first Phase 1 models (used in Phases 2 to 5)
phase1/pretrain/          clean-slate pretraining on the full corpus: prepare_corpus.py, train.py, hybrid.py, encoder.py, contamination audit, tests
phase2/ ... phase7/       one folder per task: library, notebooks, offline analysis scripts and smoke tests
```

Each phase's notebooks write `submission.zip` with `prediction.json` at its root, the Codabench format. Local `tools/` scripts are CPU checks (synthetic smoke tests, notebook dry runs) and offline analysis.
`phase7/citation_residue.py` is a leak analysis only and was never used for a submission. `phase7/vark_*.py` produced variable-length lists, which the rules do not allow; that upload failed and nothing from it is on the leaderboard.
